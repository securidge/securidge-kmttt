제거: 설정 → 앱 → 설치된 앱 → KMttt Desktop → 제거.
제거할 때 실행 중인 KMttt 서버를 끄고, Claude Code·Codex 설정에 이 프로그램이 등록한 훅과 상태 줄을 지웁니다.

Installing puts KMttt Desktop (the window app) and kmttt (the server and command-line tool) in this folder.
Uninstall: Settings → Apps → Installed apps → KMttt Desktop → Uninstall.
Uninstalling stops the running KMttt server and removes the hooks and status line this copy registered in Claude Code and Codex.
You are asked whether to delete settings and the security log (kept by default).
