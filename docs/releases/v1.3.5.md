# Securidge KMttt 1.3.5

## 1.3.5에서 바뀐 점 · What's new in 1.3.5

**한 줄 요약:** 연동이 왜 안 되는지 KMttt가 직접 알려 주고, 감사 기록 제한을 보강한 작은 업데이트입니다. 화면·설정·저장 데이터는 바뀌지 않았습니다.
**In one line:** KMttt now tells you why an agent integration is not working, and audit throttling is tightened. The window, settings and stored data are unchanged.

### 1. 연동이 안 될 때 이유를 알려 줍니다 · Why an integration is not working

- **이전(1.3.4):** `kmttt integration status`는 설치됐는지(`installed: true/false`)만 보여 줬습니다. "설치는 됐는데 알림이 안 온다"면 설정 파일을 직접 열어 봐야 했습니다.
- **이제(1.3.5):** 연동마다 이유 코드(`reason`)와 짧은 설명(`reason_text`)이 함께 나옵니다.

```
> kmttt integration status
{"agent": "claude", "installed": true, "reason": "ok", "reason_text": "integration is installed and working", ...}
{"agent": "codex",  "installed": true, "reason": "notify_other_kmttt", "reason_text": "Codex notify uses a different KMttt installation", ...}
```

- 구분하는 경우: 설정 파일이 없음(`config_missing`) · 읽을 수 없음, 예를 들어 권한 문제(`config_unreadable`) · 내용이 잘못됨(`config_invalid`), Codex 알림이 다른 프로그램(`notify_other_program`)이나 다른 KMttt 설치본(`notify_other_kmttt`)을 가리킴, Claude Code 훅이 없거나(`hooks_missing`) 일부만 있음(`hooks_partial`), `--chain`으로 연결한 프로그램이 없거나(`chain_target_missing`) 거부됨(`chain_rejected`). 정상이면 `ok`입니다.
- 새 사유 필드에는 경로·프로그램 이름·인자를 넣지 않습니다. 기존 필드(`agent`, `installed`, `file`)는 그대로라, 이 출력을 읽는 스크립트는 고칠 필요가 없습니다.

**English:** Before, `kmttt integration status` only said whether an integration was installed. Now each entry also has a fixed reason code (`reason`) and a short explanation (`reason_text`) — for example a missing, unreadable (such as a permissions problem) or invalid settings file, a Codex `notify` that points at another program or another KMttt installation, missing or partial Claude Code hooks, or a `--chain` target that is missing or refused. `ok` means it is working. The new fields never include paths, program names or arguments, and the existing fields are unchanged, so scripts that read this output keep working.

### 2. 감사 기록 제한 보강 · Audit throttling for unidentified callers

- **이전(1.3.4):** Codex 알림 연결의 감사 기록에 반복 제한을 넣었지만, 어느 창에서 왔는지 식별하지 못한 호출자들은 한 묶음으로 셌습니다. 그래서 한 호출자가 다른 호출자의 기록을 요약 쪽으로 밀어낼 수 있었습니다.
- **이제(1.3.5):** 이런 호출자는 창과 따로 세고, 요약에 `unknown callers`와 서로 다른 프로세스 수를 남깁니다.

**English:** In 1.3.4, callers KMttt could not tie to a pane shared one throttling bucket in the Codex notify-chain audit, so one could push another's records into the summary. They are now counted separately, and the summary labels them `unknown callers` with the number of distinct processes.

### 누가 업데이트하면 좋나요 · Should I update?

- **Claude Code·Codex 연동을 쓴다면 권장합니다.** 연동 문제를 바로 확인할 수 있습니다. / **Recommended if you use the Claude Code or Codex integration.**
- 그 밖에는 서두르지 않아도 됩니다. 이번 버전에는 보안 수정이 없습니다. 다만 **1.3.2보다 오래된 버전**을 쓰고 있다면 1.3.2의 보안 수정 때문에 업데이트하세요. / Otherwise there is no rush: this release has no security fix. If you are on a version **older than 1.3.2**, update for the 1.3.2 security fix.
- 올리는 법: 새 설치 파일을 실행하면 기존 버전을 덮어씁니다. 명령줄 도구만 쓰면 `kmttt update`. / Run the new installer over the old one, or `kmttt update` for the command-line tool.

## 주요 기능 · Highlights

- **멀티플렉서 · Multiplexer** — 에이전트(Claude Code, Codex CLI, OpenCode, Cursor CLI, Copilot CLI, Gemini CLI, Aider, 셸)마다 실제 터미널 창을 제공하고, 백그라운드 서버가 창을 관리합니다. 창은 끌어서 옮기고 크기를 자유롭게 조절할 수 있습니다. / A real terminal pane per agent, owned by a background server; drag panes to move them and resize freely.
- **보안 통제 · Security controls** — 사용자만 승인할 수 있는 정책 관문, 위변조 탐지 감사 로그, 민감정보 마스킹, 창별 격리 수준, 위험한 도구 호출을 차단하는 훅. / A policy gate with approvals reserved for people, a tamper-evident audit log, secret masking, per-pane isolation levels, hooks that block dangerous tool calls.
- **즉시 승인 · Answer from the banner** — 알림 막대에 요청 내용과 자동 거부까지 남은 시간, [이번만 허용] (Alt+Y)·[거부] (Alt+N). 앱이 백그라운드에 있으면 Windows 알림(알림에서는 승인 불가). / Request details, a countdown and Allow once/Deny on the banner; a Windows notification when the app is in the background (approvals cannot be granted from the notification).
- **토큰 사용량 · Token usage** — Claude Code·Codex의 분당 토큰, 15분 추이, 창별 사용량. 패널을 닫으면 읽기를 멈춥니다. / Tokens per minute, a 15-minute trend and per-pane usage; reading stops while the panel is closed.
- **AI 사용량 · AI usage** — 잔여 한도(%)와 초기화까지 남은 시간, 15% 미만이면 경고. / Remaining allowance and reset times, with an alert below 15%.
- **한국어·영어 · Korean and English** — 화면과 문서를 두 언어로 제공합니다. / Interface and documentation in both languages.

## 파일 확인 · Verifying a download

`SHA256SUMS.txt`에 모든 파일의 해시가 있고, 이 목록이 minisign으로 서명돼 있습니다. `kmttt update`는 이 검사를 스스로 합니다.
`SHA256SUMS.txt` lists the hash of every file and is signed with minisign. `kmttt update` performs this check automatically.

```
minisign -Vm SHA256SUMS.txt -P RWSsN6lcjx/Hn8RG/c/tAQnOC1Xk3A2fOCuRT5mhX7LwEZzT9nYuU80E
sha256sum -c --ignore-missing SHA256SUMS.txt        # Windows: Get-FileHash <file>
```
