## 주요 기능 · Highlights

- **멀티플렉서 · Multiplexer** — 에이전트(Claude Code, Codex CLI, OpenCode, Cursor CLI, Copilot CLI, Gemini CLI, Aider, 셸)마다 실제 터미널 창을 제공하고, 백그라운드 서버가 창을 관리합니다. 창은 끌어서 옮기고 크기를 자유롭게 조절할 수 있습니다. / A real terminal pane per agent, owned by a background server; drag panes to move them and resize freely.
- **보안 통제 · Security controls** — 사용자만 승인할 수 있는 정책 관문, 위변조 탐지 감사 로그, 민감정보 마스킹, 창별 격리 수준, 위험한 도구 호출을 차단하는 훅. / A policy gate with approvals reserved for people, a tamper-evident audit log, secret masking, per-pane isolation levels, hooks that block dangerous tool calls.
- **즉시 승인 · Answer from the banner** — 알림 막대에 요청 내용과 자동 거부까지 남은 시간, [허용](Alt+Y)·[거부](Alt+N). 앱이 백그라운드에 있으면 Windows 알림(알림에서는 승인 불가). / Request details, a countdown and Allow/Deny on the banner; a Windows notification when the app is in the background (approvals cannot be granted from the notification).
- **토큰 사용량 · Token usage** — Claude Code·Codex의 분당 토큰, 15분 추이, 창별 사용량. 패널을 닫으면 읽기를 멈춥니다. / Tokens per minute, a 15-minute trend and per-pane usage; reading stops while the panel is closed.
- **AI 사용량 · AI usage** — 잔여 한도(%)와 초기화까지 남은 시간, 15% 미만이면 경고. / Remaining allowance and reset times, with an alert below 15%.
- **한국어·영어 · Korean and English** — 화면과 문서를 두 언어로 제공합니다. / Interface and documentation in both languages.

## 1.3.2 이후 바뀐 점 · Changes since 1.3.2

- **Codex 기존 알림과 함께 쓰기 · Keep your existing Codex notifier** — Codex에 이미 `notify`(예: Codex 앱의 computer-use)가 있어도 KMttt를 연동할 수 있습니다. `kmttt integration install codex --chain`은 KMttt 보고 뒤에 기존 알림을 이어서 실행합니다(직접 등록한 네이티브 실행 파일만 — Windows는 `.exe` — 셸·스크립트는 거부, 3초 제한). `--replace`는 기존 알림을 멈추고 KMttt로 바꾸며, 연동을 해제하면 원래 설정으로 되돌립니다. 옵션이 없으면 지금처럼 기존 설정을 건드리지 않고 거부합니다. / Connect KMttt even when Codex already has a `notify` (such as computer use in the Codex app): `--chain` runs your existing notifier after KMttt's report, but only a native executable you register (an `.exe` on Windows); shells and scripts are refused, and it has a 3-second limit. `--replace` swaps it out and restores it when you disconnect. Without either option, KMttt refuses to connect and leaves your setting alone.
- **승인 처리 보강 · More robust approval handling** — 세션 허용을 적용할 수 없는 요청에 세션 허용을 고르면 실행을 허용하지 않고 요청을 그대로 남겨 다시 고를 수 있게 했고, 이미 처리된 승인을 다시 결정하면 거부합니다. / Choosing "Allow for this session" where it does not apply now leaves the request pending instead of allowing it, and an approval that was already answered can no longer be decided again.
- **문법 오류가 있는 Codex 설정에서도 동작 · Handling invalid Codex settings** — Codex 설정 파일에 문법 오류가 있어도 연동 상태 확인, 스킬 갱신, 연동 해제·프로그램 제거가 끝까지 동작합니다. / Status, skill refresh, disconnect and uninstall keep working even when Codex's config file has errors.

## 파일 확인 · Verifying a download

`SHA256SUMS.txt`에 모든 파일의 해시가 있고, 이 목록이 minisign으로 서명돼 있습니다. `kmttt update`는 이 검사를 스스로 합니다.
`SHA256SUMS.txt` lists the hash of every file and is signed with minisign. `kmttt update` performs this check automatically.

```
minisign -Vm SHA256SUMS.txt -P RWSsN6lcjx/Hn8RG/c/tAQnOC1Xk3A2fOCuRT5mhX7LwEZzT9nYuU80E
sha256sum -c --ignore-missing SHA256SUMS.txt        # Windows: Get-FileHash <file>
```
