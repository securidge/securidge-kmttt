## 바뀐 점 · What changed

- **보호 창에서 로그인 · Sign-in in protected panes** — Claude Code의 `/login`이 토큰 교환 단계(`platform.claude.com`)에서 막히고, Codex가 `chatgpt.com`에 닿지 못하던 문제를 고쳤습니다. 에이전트의 로그인·인증·모델 호출 주소(Claude: anthropic.com·claude.ai·claude.com, Codex: auth.openai.com·api.openai.com·chatgpt.com)를 허용 목록과 따로 항상 허용합니다. 허용 목록을 직접 저장해 둔 경우에도 적용됩니다. 원격 측정 주소는 계속 막습니다. [설정 → 보호]에서 끌 수 있습니다. / Claude Code `/login` failed at the token exchange and Codex could not reach `chatgpt.com`. The agents' sign-in, authentication and model addresses are now always allowed, even with a saved allow list; telemetry stays blocked. Turn it off in Settings → Protection.
- **경고가 줄었습니다 · Fewer warnings** — 같은 창이 같은 주소로 반복해 막히면 10분에 한 줄(알림)로 묶습니다. 한 창이 10분 안에 서로 다른 주소 8곳 이상에서 막힐 때만 경고합니다. 보안 기록에 어느 창인지 나오고, 차단 줄의 [이 주소 허용]으로 바로 허용할 수 있습니다(확인 창). / Repeated blocks are grouped into one info line every 10 minutes; a warning appears only when a pane is blocked on 8+ addresses in 10 minutes. The log shows the pane, and [Allow this address] adds it after a confirmation.
- **창 크기·위치 · Pane size and position** — 제목 줄을 끌어 다른 창 위에 놓으면 옮겨집니다(가운데: 자리 바꾸기, 가장자리: 그쪽에 붙이기, Esc: 취소). 경계선이 보이고 잡기 쉬워졌으며 두 번 누르면 반반이 됩니다. 단축키: 창 크게/작게 Ctrl+Alt+= / Ctrl+Alt+-, 모든 창 크기 같게 Ctrl+Alt+0, 옆 창과 자리 바꾸기 Ctrl+Alt+Shift+방향키. / Drag a title row onto another pane (center swaps, an edge places it on that side, Esc cancels). Visible, easier-to-grab dividers; double-click to split evenly. Shortcuts: enlarge/shrink Ctrl+Alt+= / Ctrl+Alt+-, equal sizes Ctrl+Alt+0, swap with a neighbor Ctrl+Alt+Shift+arrow.

## 파일 확인 · Verifying a download

`SHA256SUMS.txt`에 모든 파일의 해시가 있고, 이 목록이 minisign으로 서명돼 있습니다. `kmttt update`는 이 검사를 스스로 합니다.
`SHA256SUMS.txt` lists the hash of every file and is signed with minisign. `kmttt update` does this check by itself.

```
minisign -Vm SHA256SUMS.txt -P RWSsN6lcjx/Hn8RG/c/tAQnOC1Xk3A2fOCuRT5mhX7LwEZzT9nYuU80E
sha256sum -c --ignore-missing SHA256SUMS.txt        # Windows: Get-FileHash <file>
```
