## 주요 기능 · Highlights

- **멀티플렉서 · Multiplexer** — 에이전트(Claude Code, Codex CLI, OpenCode, Cursor CLI, Copilot CLI, Gemini CLI, Aider, 셸)마다 실제 터미널 창을 주고, 백그라운드 서버가 창을 소유합니다. / A real terminal pane per agent, owned by a background server.
- **보안 통제 · Security controls** — 사람만 승인하는 정책 관문, 위변조 방지 기록, 비밀값 가리기, 창별 보호 수준, 위험한 도구 호출을 막는 훅. / A policy gate only a person can approve, a tamper-evident log, secret masking, per-pane protection levels, hooks that block dangerous tool calls.
- **바로 승인 · Answer from the banner** — 노란 띠에 요청 내용과 자동 거부까지 남은 시간, [허용](Alt+Y)·[거부](Alt+N). 앱이 뒤에 있으면 Windows 알림(알림에서는 승인 불가). / Request details, a countdown and Allow/Deny on the banner; a Windows notification when the app is in the background (no approving from it).
- **현재 토큰 사용량 · Token usage** — Claude Code·Codex의 분당 토큰, 15분 추이, 창별 사용량. 접어 두면 아무것도 읽지 않습니다. / Tokens per minute, a 15-minute trend and per-pane usage; nothing is read while it is closed.
- **AI 사용량 · AI usage** — 남은 사용량(%)과 리셋까지 남은 시간, 15% 미만이면 경고. / Remaining usage and reset times, with an alert below 15%.
- **한국어·영어 · Korean and English** — 화면과 문서를 두 언어로 제공합니다. / Interface and documentation in both languages.

## 파일 확인 · Verifying a download

`SHA256SUMS.txt`에 모든 파일의 해시가 있고, 이 목록이 minisign으로 서명돼 있습니다. `kmttt update`는 이 검사를 스스로 합니다.
`SHA256SUMS.txt` lists the hash of every file and is signed with minisign. `kmttt update` does this check by itself.

```
minisign -Vm SHA256SUMS.txt -P RWSsN6lcjx/Hn8RG/c/tAQnOC1Xk3A2fOCuRT5mhX7LwEZzT9nYuU80E
sha256sum -c --ignore-missing SHA256SUMS.txt        # Windows: Get-FileHash <file>
```
